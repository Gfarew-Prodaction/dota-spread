# Быстрый поиск с SteamApis

Ускорение поиска работает в два этапа: одна массовая выгрузка помогает выбрать возможные выгодные предметы, затем очередь перепроверяет лучшие предложения на страницах Steam. В таблицу попадают только ордера, полученные непосредственно из Steam. Скачивание выгрузки не делает старые ордера свежими и не увеличивает лимит прямых запросов Steam.

## Подключение

1. Открой [SteamApis](https://steamapis.com/) и войди через свой Steam-аккаунт.
2. В Settings получи **ключ SteamApis**. Обычный ключ с `steamcommunity.com/dev/apikey` здесь не подходит.
3. Уточни доступ своего тарифа к **v2 App Price List для Dota 2, appid 570**, наличие полей `orderBook.highestBuy`, `buyOrdersTop10`, `histogramAgeSeconds` и допустимое число запросов. Это отдельный сторонний сервис; доступ может требовать оплаты. Не оплачивай тариф без проверки этих условий.
4. В Render открой **dota-spread → Environment → Edit**. Эта кнопка справа сверху блока **Environment Variables**, как на твоём первом скриншоте. Добавь строку:

   | Key | Value |
   | --- | --- |
   | `STEAMAPIS_KEY` | твой ключ SteamApis |
   | `STEAMAPIS_REFRESH_INTERVAL` | `60` или больший интервал, соответствующий тарифу |
   | `STEAMAPIS_CURRENCY` | `USD` либо `EUR`, согласно валюте выгрузки |

5. Нажми **Save, rebuild, and deploy** либо доступную кнопку сохранения с перезапуском. Дождись **Live**. Ключ не присылай в чат и не добавляй в GitHub или переменные `VITE_*`.
6. Открой сайт. При успешной загрузке появится сообщение о числе сопоставленных ордеров. Счётчик «Проверено в Steam» по-прежнему считает прямые проверки. В [диагностике сайта](https://dota-spread.onrender.com/api/health) ожидаются `bulk_configured: true` и `scanner_mode: "hybrid"`.

Документация v2 не указывает валюту числового поля `highestBuy` на странице App Price List. Поэтому её нужно уточнить для своего доступа. По умолчанию для **приоритета очереди** предполагается USD. Это предположение не используется для цен в таблице: они всегда рассчитываются из фактической валюты ответа Steam.

Если выгрузка размещена на CDN вне доменов `steamapis.com`, адаптер отклонит редирект. В таком случае нужен официальный адрес CDN для добавления в разрешённый список. Ключ передаётся только первому запросу API и не отправляется CDN.

## Что работает до подключения

Без ключа сайт продолжает работать бесплатно. Основная очередь сосредоточена на 200 предметах в диапазоне $0,50–50 с большим наличием на Lis-Skins. Наличие — ориентир для поиска, а не доказательство спроса. Уже найденные выгодные ордера перепроверяются; каждый десятый запрос выделяется поиску за пределами основной группы. Падение цены Lis-Skins также получает приоритет. Размер группы меняется через `STEAM_PRIORITY_SIZE`. Для переноса сбора на свой Mac есть [бесплатный домашний сборщик](LOCAL-COLLECTOR.md).

Массовая выгрузка обрабатывается отдельно от Lis-Skins и прямого Steam. Для приоритета используется лучший buy order с количеством именно по этой цене, а не все заявки в стакане. Выгрузки и гистограммы старше суток не участвуют в приоритете. Время берётся из источника с учётом `histogramAgeSeconds`, а не из момента скачивания. API-ошибка сохраняет прошлые данные и не ставит прямой Steam на паузу. Общая PostgreSQL координирует запросы SteamApis нескольких процессов.

Фоновое обновление по умолчанию раз в минуту — это частота скачивания, а не обещание обновления всех ордеров у поставщика раз в минуту. Получение полного списка также не равнозначно моментальной перепроверке всех предметов. Пока действует пауза прямого Steam, подтверждение новых сделок ждёт её окончания.

Официальные источники: [App Price List](https://docs.steamapis.com/items/app-list), [получение ключа и авторизация](https://docs.steamapis.com/getting-started/quick-start).
